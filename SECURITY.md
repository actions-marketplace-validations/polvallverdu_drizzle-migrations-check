# Security policy

## Supported versions

Only the latest release of the current major version (`v1`) gets security fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/polvallverdu/drizzle-migrations-check/security/advisories/new).
You'll get a reply within a few days. Once a fix is released, the advisory is published with
credit to you (unless you'd rather stay anonymous).
